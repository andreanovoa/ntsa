# `ntsa.tools.statistics`

| Function | One-liner |

| `fun_PSD(dt, X)` | Power spectral density of one or more signals: `(f, PSD)`. |
| `autocorrelation(x, n_lags)` | Normalized ACF, `acf[0]=1`. |
| `signal_stats(x, dt, n_bins=64)` | Dict of moments, PSD, PDF and ACF. |
